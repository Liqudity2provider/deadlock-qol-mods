# Graphics toggle

`assets/cfg/qol_fast.cfg` and `assets/cfg/qol_pretty.cfg` ship inside the VPK, so the menu's graphics buttons
(`exec qol_fast` / `exec qol_pretty` through `CitadelConCommand`) and the console find them without extra files.
Source and measurements: [../../../perf](../../../perf).
